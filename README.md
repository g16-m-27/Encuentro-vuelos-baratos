# ✈️ Sistema de Encuentro de Vuelos Baratos

## Descripción

Este proyecto consiste en el desarrollo de un sistema en Python para organizar y consultar información sobre vuelos, permitiendo identificar opciones económicas según los datos registrados.

## Objetivo

Facilitar la búsqueda y comparación de vuelos mediante el uso de estructuras de datos, permitiendo consultar rutas, filtrar precios, identificar el vuelo más barato y ordenar los vuelos según su costo.

## Tecnologías utilizadas

- **Lenguaje:** Python
- **Entorno de desarrollo:** Visual Studio Code
- **Estructura de datos:** Lista de diccionarios

## Información de los vuelos

Cada registro contiene los siguientes datos:

- ID del vuelo
- Ciudad de origen
- Ciudad de destino
- Aerolínea
- Fecha
- Precio en dólares

El sistema cuenta con **10 vuelos de prueba** para demostrar el funcionamiento de las diferentes operaciones.

##  Funcionalidades

El programa permite:

- Visualizar los vuelos registrados.
- Buscar vuelos por ciudad de origen y destino.
- Filtrar vuelos según un precio máximo.
- Filtrar vuelos por aerolínea.
- Filtrar vuelos por fecha.
- Identificar el vuelo más barato.
- Identificar el vuelo más barato de una ruta.
- Ordenar los vuelos de menor a mayor precio.
- Preparar los datos necesarios para las gráficas del proyecto.

##  Ejecución

Para ejecutar el programa se necesita tener Python instalado.

Desde la terminal de Visual Studio Code se puede ejecutar con:

```bash
python vuelos.py
```

Luego, el sistema solicitará los datos necesarios para realizar la búsqueda y el filtrado de vuelos.
